# Nicole M. Tutoring

Source for [www.nicolemtutoring.com](https://www.nicolemtutoring.com), a single-page site for Nicole M. Tutoring, hosted via GitHub Pages.

## Structure

- `index.html` / `styles.css`: the site
- `assets/`: logo, section dividers, and footer illustrations
- `CNAME`: custom domain config for GitHub Pages

## Deploy

Pushes to `main` publish automatically via GitHub Pages.
